# Purpose

This document defines the standard startup procedure that every AI shall follow before participating in an engineering session for AEVON.

Its purpose is to ensure that every engineering session begins with sufficient context, a clear understanding of the current objective, and consistent adherence to the established governance.

---

# Scope

This document defines:

- Session initialization.
- Governance review.
- Context loading.
- Project state verification.
- Milestone identification.
- Engineering readiness verification.

This document does not define the AI's responsibilities, collaboration rules, project context, current project state, engineering tasks, or migration procedures.

---

# Startup Protocol

Every engineering session shall begin by completing the following steps in sequence.

## Step 1 — Confirm Project

Confirm that the current project is AEVON.

If the project cannot be identified, request clarification before continuing.

---

## Step 2 — Review Governance

Review the mandatory AI Collaboration Governance documents to understand the operating standards applicable to the current session.

---

## Step 3 — Load Required Context

Load all project context necessary to understand the current engineering work.

Review additional governance documents when required by the current task.

---

## Step 4 — Verify Current State

Understand the current state of the project.

Confirm:

- Current milestone.
- Current engineering objective.
- Existing progress.
- Known blockers, if any.

---

## Step 5 — Identify Current Task

Clearly identify the task that is expected to be completed during the current engineering session.

If multiple tasks are available, confirm the active task before proceeding.

---

## Step 6 — Verify Readiness

Before beginning engineering work, confirm that:

- Required governance has been reviewed.
- Required context has been loaded.
- The current milestone is understood.
- The current task is clear.
- No critical information is missing.

If any required information is unavailable, request clarification before continuing.

---

## Step 7 — Begin Engineering

Begin engineering work only after successfully completing the previous steps.

Remain focused on the current milestone until it is completed or explicitly changed by the engineering team.

---

# Startup Principles

Every startup shall follow these principles:

- Understand before acting.
- Clarify before assuming.
- Follow governance before implementation.
- Focus on one milestone at a time.
- Preserve engineering continuity throughout the session.

---

# Completion Criteria

The startup protocol is complete when the AI can confidently answer the following questions:

- What project am I working on?
- What governance applies to this session?
- What is the current milestone?
- What is today's engineering task?
- Do I have sufficient context to begin?

Only after all questions have been answered should engineering work begin.
