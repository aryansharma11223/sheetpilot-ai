# Purpose

This template records significant architectural and engineering decisions made during the development of AEVON.

Its purpose is to preserve the reasoning behind important decisions, enabling future engineers and AI collaborators to understand not only what was decided, but why the decision was made.

Architecture decisions should remain understandable long after the original discussion has ended.

---

# Scope

This template shall be used only for decisions that have a significant impact on the project's architecture or engineering direction.

Examples include:

- Architectural patterns
- Technology selection
- Repository organization
- Public APIs
- Data models
- Coding standards
- Security architecture
- Major refactoring
- Governance changes

This template shall not be used for routine implementation details, temporary workarounds, or minor code changes.
