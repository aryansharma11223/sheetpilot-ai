# Purpose

A milestone is not considered complete when development ends.

A milestone is considered officially closed only after engineering, verification, documentation, governance, repository management, and milestone sign-off have all been completed.

This checklist defines the standard milestone closure workflow for AEVON.

---

# Scope

This checklist applies to every milestone within AEVON, regardless of size or engineering discipline.

It shall be completed before a milestone is officially marked as closed.
